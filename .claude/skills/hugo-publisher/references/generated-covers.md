# Register of generated covers

Check this before designing a cover (`featured-image.md`, "What must differ"): pick a background tone and
accent hue that are not already in the table, and a type pairing nobody uses yet. **After publishing, add a
row for the new cover.** A subagent can also be asked to look at an existing cover (see `SKILL.md` hard rule
2) when the table isn't enough, e.g. to check composition.
